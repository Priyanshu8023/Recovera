# Part 5: Remediation & Safety

Knowing the problem is only half the battle. Fixing it safely is where Recovera shines.

## Safety Guardrails (Policy Engine)
Not all AI suggestions should be applied blindly. Recovera enforces hardcoded guardrails.
- **Low Risk**: e.g., fixing a typo or CSS bug. Allowed to Auto-PR.
- **Medium Risk**: e.g., modifying an API endpoint. Auto-PR but requires human review.
- **Critical Risk**: e.g., Auth, Payments, Database Migrations. **Strictly requires human approval** before any code is written.

## Automated Pull Requests
If the policy allows, Recovera uses the GitHub API (Octokit) to:
1. Create a new branch (e.g., `recovera/fix-payment-null-ptr`).
2. Apply the AI's `suggested_fix_code` to the specific file.
3. Commit the change and open a Pull Request.

### Example Code: Opening a PR
```typescript
await octokit.pulls.create({
  owner: "Priyanshu8023",
  repo: "Recovera",
  title: "Auto-Fix: NullPointerException in Payment API",
  head: "recovera/fix-payment-null-ptr",
  base: "main",
  body: "This PR was generated by Recovera to fix an anomaly detected in production. Root cause: Missing null check for billing info."
});
```
Engineers receive an alert in Slack to review the PR.
